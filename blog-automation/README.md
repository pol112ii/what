# 블로그 자동화 — 키워드 수집기 (크롬 확장 프로그램)

네이버 트렌드(데이터랩)에서 키워드를 수집하고, **경쟁력(비율 / 검색량)** 을 계산해
상위노출이 쉬운 키워드를 골라주는 크롬 확장 프로그램입니다.
(채팅에서 본 박성호님 시스템을 Claude Code로 재현하는 프로젝트)

> ⚠️ 네이버 블로그 자동 발행은 네이버 약관상 회색지대이며 계정 제재 위험이 있습니다.
> 본인 계정·개인 사용 범위에서만 사용하세요. 책임은 사용자에게 있습니다.

## 현재까지 구현 (v0.1 — 1단계)

- ✅ 크롬 확장 프로그램 뼈대 (Manifest V3, 사이드패널)
- ✅ 스크린샷과 동일한 UI (탭/체크박스/경쟁력순 정렬)
- ✅ 키워드 수집 (열려 있는 데이터랩 탭에서 NEW 항목 긁어오기) + 직접 입력
- ✅ 경쟁력 계산 엔진
  - 검색량: 네이버 **검색광고 API** (HMAC 서명)
  - 문서수: 네이버 **검색 API** (블로그 total)
  - 비율 = 문서수 / 검색량 → `0.002 / 61` 형태로 표시
- ✅ 정렬(경쟁력/최신/가나다), 선택, 설정 저장, 글쓰기 기록 뷰

## 다음 단계 (예정 — 박성호님 시스템 기준)

- ⏳ 선택 키워드로 본문 자동 생성 (LLM API)
- ⏳ 이미지 프롬프트 생성 → 제미나이에서 생성 → 저장 위치 기억 → 자동 삽입
- ⏳ 네이버 블로그 글쓰기 페이지 자동 입력 + 발행
- ⏳ 자동 글쓰기 간격(랜덤 10~12분) 스케줄러

## 설치 방법

1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 `blog-automation` 폴더 선택
4. 툴바의 확장 아이콘 클릭 → 사이드패널 열림

## API 키 발급

### 1) 네이버 검색 API (문서수)
- https://developers.naver.com/apps/#/register 에서 애플리케이션 등록
- 사용 API: **검색** 선택 → Client ID / Client Secret 발급
- 설정 탭에 입력

### 2) 네이버 검색광고 API (검색량)
- https://searchad.naver.com → 로그인 → 도구 → **API 사용 관리**
- API Key / Secret Key 발급, 우측 상단 계정의 **Customer ID** 확인
- 설정 탭에 입력

## 사용 흐름

1. **설정** 탭에서 API 키 4종 입력 → 저장
2. 네이버 **데이터랩** 페이지를 브라우저에 연다
3. 확장 사이드패널에서 **수집** → 키워드가 목록에 채워짐
4. 계산할 키워드 체크 → **선택 키워드 경쟁력 계산**
5. **경쟁력순** 정렬 → 비율 낮고 검색량 적당한 키워드 선택

## 파일 구조

```
manifest.json            확장 프로그램 정의 (MV3)
background.js            서비스 워커 (API 호출 중계 — CORS 우회)
sidepanel.html/.css/.js  메인 UI (사이드패널)
lib/storage.js          설정/상태 저장 (chrome.storage.local)
lib/naverAd.js          검색광고 API (HMAC 서명, 검색량)
lib/naverSearch.js      검색 API (블로그 문서수)
lib/competition.js      경쟁력 계산 (비율 = 문서수/검색량)
lib/datalabCollector.js 데이터랩 DOM 스크래퍼 (선택자 튜닝 필요할 수 있음)
icons/                  아이콘
```

## 알려진 한계 / 튜닝 포인트

- **데이터랩 수집 선택자**: 네이버가 페이지 구조를 바꾸면 `lib/datalabCollector.js`
  의 선택자를 실제 페이지에 맞게 조정해야 합니다. (개발자도구로 확인)
- 검색광고 API 는 키워드 공백을 제거해서 보냅니다(이미 처리됨).
- 검색량이 매우 낮으면 `< 10` 으로 와서 0으로 정규화됩니다.
