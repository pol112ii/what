# 🍽️ 칼로리 체크 앱

목표 칼로리를 정해두고 먹은 칼로리를 차감하며, 음식 데이터를 검색해 무게(g)만 입력하면 칼로리를 자동 계산해주는 칼로리 트래킹 웹앱입니다.

## 📱 페이지 구성 (하단 탭으로 이동)
| 페이지 | 경로 | 설명 |
|--------|------|------|
| 🏠 홈 | `index.html` | 오늘의 목표/남은 칼로리, 직접 입력·빠른 추가, 기록 목록 |
| 🔎 칼로리 체크 | `search.html` | 음식 **검색** → 무게(g) 입력 → 칼로리 자동 계산 → 오늘 기록에 추가 |
| 🍚 음식 관리 | `foods.html` | 음식 데이터(이름·100g당 kcal·분류) **추가/삭제** (DB 저장) |

## ✅ 구현된 기능
### 홈 (index.html)
- 목표 칼로리 설정 → 먹은 칼로리 자동 차감
- 음식 이름(선택) + 칼로리 직접 입력
- 빠른 추가 버튼 (+100/+200/+300/+500)
- 진행 바 + 목표 초과 시 빨간색 표시
- 기록 목록 + 개별 삭제, 전체 지우기
- localStorage 자동 저장 + **하루 지나면 기록 자동 초기화**(목표는 유지)

### 칼로리 체크 (search.html)
- 음식 이름으로 **실시간 검색** (DB에 저장된 데이터에서 검색, 인터넷 검색 X)
- 음식 선택 → 무게(g) 입력 → `100g당 kcal × g ÷ 100` 으로 자동 계산
- "오늘 기록에 추가하기" → 홈의 기록과 **공유**되어 남은 칼로리에 반영
- 추가 시 토스트 알림

### 음식 관리 (foods.html)
- 음식 이름 + 100g당 칼로리 + 분류(선택) 입력해 **DB에 저장**
- 등록된 음식 목록 보기 + 삭제
- 여기서 추가한 음식은 칼로리 체크 검색에 바로 나타남

## 💾 데이터 저장
### 1) 오늘의 기록 (localStorage)
- 키: `calorie-check-v1`
- 형식: `{ "date": "2026-06-19", "goal": 2000, "items": [ { "name": "흰쌀밥 150g", "cal": 195 } ] }`
- 사용 중인 브라우저에만 저장됩니다.

### 2) 음식 데이터 (로컬 JSON 시드 + localStorage)
- 모듈: **`js/foodStore.js`** (`FoodStore`)
- 키: `calorie-foods-v1`
- 필드: `id`, `name`(음식 이름), `per100g`(100g당 kcal), `category`(분류)
- 동작 방식:
  - **최초 실행 시** `data/foods.json` 의 기본 음식 20종으로 자동 시드합니다.
    (`fetch` 가 막히는 `file://` 환경에서는 `foodStore.js` 내장 기본 데이터로 대체)
  - 이후 사용자가 추가/삭제한 내용은 **localStorage 에 영구 저장**됩니다.
- API (모두 Promise 반환):
  - `FoodStore.list()` — 전체 음식 목록(이름순)
  - `FoodStore.add({ name, per100g, category })` — 음식 추가
  - `FoodStore.remove(id)` — 음식 삭제
- ⚠️ 음식 데이터는 **사용 중인 브라우저(기기)에만** 저장됩니다. 기기 간 공유가
  필요하면 추후 Supabase/Firebase 등 클라우드 DB로 `FoodStore` 구현만 교체하면 됩니다.
- 기본 데이터 20종(흰쌀밥, 닭가슴살, 삶은 계란, 고구마, 바나나 등)이 들어 있습니다.

## 🚀 사용 흐름 예시
1. **음식 관리**에서 자주 먹는 음식을 등록 (예: 흰쌀밥 130, 김밥 150)
2. **칼로리 체크**에서 "흰쌀밥" 검색 → 선택 → `150` 입력 → 약 **195kcal** 계산 → 추가
3. **홈**에서 남은 칼로리가 자동으로 줄어든 것을 확인
